
# Neural Networks from Scratch

## Description

The assignment focuses on building a binary classification model from scratch using Python and NumPy.

It starts with a single neuron and gradually develops into a neural network with one hidden layer.

## Topics Covered

- Creating a neuron
- Initializing weights and biases
- Sigmoid activation function
- Forward propagation
- Cost calculation
- Gradient descent
- Model training
- Model evaluation
- Building a neural network with one hidden layer
- Plotting training cost

## Technologies

- Python 3
- NumPy
- Matplotlib

## Repository

- Repository: `alu-machine_learning`
- Directory: `supervised_learning/classification`

## Files

- `0-neuron.py` – Creates a basic neuron
- `1-neuron.py` – Adds private attributes
- `2-neuron.py` – Implements forward propagation
- `3-neuron.py` – Calculates cost
- `4-neuron.py` – Evaluates predictions
- `5-neuron.py` – Implements gradient descent
- `6-neuron.py` – Trains the neuron
- `7-neuron.py` – Adds training output and graphs
- `8-neural_network.py` – Creates a neural network
- `9-neural_network.py` – Adds private attributes and getters
- `10-neural_network.py` – Implements neural network forward propagation
